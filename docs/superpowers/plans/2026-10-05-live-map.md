# Live bus map (frontend v1) Implementation Plan

> **For agentic workers:** Execute inline (no subagents; user policy). Steps use checkbox (`- [ ]`) syntax.

**Goal:** A static Svelte 5 app at `https://bus.haroldpoi.dev` that shows live OASA vehicles for up to 5 chosen lines, per `docs/CONTRACT.md`, with feature parity to upstream `oasa_rt/viewer.html`.

**Architecture:** Pure TS modules hold all logic that can break silently (poll scheduling, URL selection state, formatting, glide math) and are unit-tested with Vitest + fake timers. One `AppState` class (`$state` fields) is the single store; Svelte components render it. MapLibre GL v6 draws routes/stops as GeoJSON layers and vehicles as HTML `Marker`s (≤ ~150 vehicles for 5 lines, so DOM markers are cheap and give crisp line-number pills and easy per-frame glide).

**Tech Stack:** Svelte 5.57 (runes), Vite 8, TypeScript, MapLibre GL 6.12 + OpenFreeMap (`positron` light / `dark` dark style), Vitest 4.

---

## Decisions (with reasons)

1. **MapLibre + OpenFreeMap**, not Leaflet + OSM raster: no key, no usage cap, OSM tile policy discourages app traffic. Cost: ~230 KB gz bundle. WebGL2 is required in v6; if `GPUInitializationError` is thrown, show a Greek error card.
2. **Vehicles as DOM `Marker`s**, routes/stops/highlight as GeoJSON layers. Avoids glyph/sprite setup and keeps the upstream look (pill with line number, delay color).
3. **Info card instead of map popups**: bottom sheet on phones (<640 px), floating card on desktop. Popups cover the bus on small screens.
4. **Selection in URL**: `?l=040,Α1` (comma list, Greek ids, max 5, order kept, deduped, Latin look-alikes → Greek). `history.replaceState` on change (no back-button spam). Unknown ids are dropped after `lines.json` loads.
5. **Mock mode** (`VITE_MOCK=1`): `api.ts` swaps in `mock.ts` (dynamic import, tree-shaken from prod). Mock serves fixtures with `updated_at = now`, `next_update_at = now + 30`, and moves each vehicle a few shape points per tick to show gliding.
6. **Config via env**: `VITE_API_BASE` (default `https://transit.haroldpoi.dev`), `VITE_STATIC_BASE` (default `https://angelospk.github.io/athens-transit-rt/static/v1`).
7. Fixtures live in `src/fixtures/` with the contract names (`line-040.json`, `lines-040.json`, `lines.json`, `status.json`) plus extra lines (`550`, `Α1`, `2`). Generated from the public OASA telematics API until the backend commits `docs/fixtures/`; then replaced.

## Poll scheduling rules (the contract, as testable rules)

Per line, one `LinePoller`. After each fetch attempt finishes at time `now` (ms), with `lastStart` = start time of that attempt:

| Outcome | Delay before next fetch |
|---|---|
| 200 | `target = next_update_at*1000 + jitter(1000..3000)`; `delay = target - now` |
| 503 `warming_up` | 10 s (+ 0..2 s jitter) |
| 429, other 5xx, network error | `min(10 s · 2^(errors-1), 120 s)` + 0..2 s jitter (errors = consecutive failures, ≥ 1) |
| 404 `unknown_line` | stop polling; show "Άγνωστη γραμμή" and remove line from selection |

Then always:
- floor: next start ≥ `lastStart + 5 s` (never faster than 5 s, even if `next_update_at` is in the past).
- ceiling: delay ≤ 300 s (protects against a bad `next_update_at`).
- hidden tab: next start ≥ `lastStart + 60 s`.
- On `visibilitychange` → visible: reschedule to `max(normalTarget, lastStart + 5 s)` so a returning user gets fresh data at once, never a burst.
- Only one request in flight per line; `stop()` aborts the in-flight fetch (`AbortController`) and clears the timer.
- No `?t=` cache-buster and no `cache: "no-store"`: we want the shared Cloudflare cache.

The pure function `nextDelay(input) → ms` encodes the table + floor/ceiling/hidden. `LinePoller` owns timers, abort, visibility.

## Changes after Codex plan review (round 1)

1. **Clock skew.** The contract has no server clock. `ClockOffset` estimates `offset = serverNow − clientNow` from each 200: since `updated_at ≤ serverNow` and a cached copy is served only until `next_update_at`, `t = next_update_at − serverNow ∈ [−2 s, next_update_at − updated_at]`, so `offset ∈ [next − recv − interval, next − recv + 2 s]`. Intersect the bounds over responses (reset on contradiction), use the midpoint. The error is ≤ interval/2 after one response and shrinks after the first on-time refetch. The same offset corrects "πριν …" counters. Also ask backend (contract issue) to expose `Date` via `Access-Control-Expose-Headers`.
2. **Absolute deadlines, monotonic time.** `outcomeDelay()` (pure) gives the delay from completion: ok → `clamp(next·1000 − (wallNow + offset), 0, interval) + 1 s + jitter·2 s` (interval invalid → 300 s cap); warming → 10 s + jitter; error → `min(10 s·2^(n−1), 120 s) + jitter`. The poller stores `baseDeadline = monoDone + outcomeDelay` (jitter sampled once) and arms `max(baseDeadline, lastStart + (hidden ? 60 s : 5 s))`. Visibility changes only re-clamp; they never bypass backoff. At fire time it re-checks and re-arms if not yet eligible.
3. **Lifecycle.** `start()` is idempotent; a generation token drops late results; abort is not an error; pollers live in a registry so pacing survives deselect/reselect (reselect shows cached data at once, fetches when eligible); 15 s request timeout counts as a network error.
4. **Responses.** Validate 200 bodies (finite times, vehicles array) else error. Other 4xx → error backoff. Non-JSON bodies keep the HTTP status. Keep last vehicles on transient failures.
5. **Status** refreshes every 60 s. Freshness is per line (chip shows stale), badge shows "Χωρίς ενημέρωση" if any selected line is > 120 s old.
6. **Map state.** Selection types: vehicle, route; stop click → small MapLibre popup with the stop name. Selected vehicle gone or line removed → close card. Variant change → highlight follows (derived). Explicit `[lat, lon]` → `[lon, lat]`. Null variant / missing stop → rows omitted.
7. **Parity additions.** Listbox keys Home/End/Space/Tab, outside-click close, map padding for the panel/card, an invisible 14 px route hit layer, live-updating card, feed clock tooltip, median "+3,0 λεπτά". Counts: vehicles = all in selected lines; "με δρομολόγιο" = `trip_id != null`; median over non-null `delay_s`. Deliberate limits (README): no "all lines" view, no SSE, no terminus-waiting state yet.
